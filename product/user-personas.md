# Palworld Breeding Combos — User Personas

Status: ACTIVE
Date: 2026-07-19

## Product in one sentence

An independent Palworld 1.0 breeding calculator that helps players check offspring, find parent combinations, and build a short breeding route from Pals they already own.

## Primary persona — Returning 1.0 player

- Situation: Returns after a game update and finds that an older combo, spreadsheet or guide may no longer match the current roster.
- Goal: Get a current answer before spending Cake and play time.
- Entry query: `palworld breeding calculator 1.0`, `palworld breeding combos`, or `how to breed {Pal}`.
- Main workflow: Choose a target Pal, compare parent pairs, and confirm the displayed game/data version.
- Main anxiety: “Is this result current and can I trust it?”
- Success: Finds a usable pair in a few minutes and sees the version evidence without reading technical documentation.

## Secondary persona — Mid-game practical breeder

- Situation: Has a limited Palbox and does not own legendary or late-game parents shown by theoretical calculators.
- Goal: Reach a target using Pals already available in the current save.
- Main workflow: Select owned Pals, exclude unsuitable parents, and build a short chain.
- Main anxiety: “The combo is technically correct, but I cannot make it.”
- Success: Receives a reachable route with clear steps and no impossible starting parent.

## Secondary persona — First-time breeder

- Situation: Knows which Pals they have or want, but does not understand breeding power, special combinations, or calculator terminology.
- Goal: Learn which starting mode matches the immediate question.
- Main workflow: Choose among “I have two parents”, “I want a specific Pal”, and “I want to use Pals I own”.
- Main anxiety: “What does this site do, and which box should I use?”
- Success: Starts the correct workflow without reading a formula guide.

## Secondary persona — Optimizer

- Situation: Plans repeated breeding for efficient progression, traits or longer chains.
- Goal: Compare direct pairs and minimize breeding generations under constraints.
- Main workflow: Reverse lookup, one-parent exploration, then chain planning.
- Main anxiety: “Is there a shorter or more practical route?”
- Success: Gets deterministic steps, can share the target URL, and can repeat the calculation.

## Shared usage scenarios

1. Two parents are already in the Palbox and the player wants to predict the child.
2. The player wants one named Pal and needs all direct parent options.
3. The player owns only part of the roster and needs a reachable multi-step route.
4. An older guide disagrees with the current game and the player needs version evidence.

## Product boundaries

- English names and Paldeck numbers are supported in the current release.
- The owned-Pals list stays in the browser; there is no account or save-file upload.
- The site is free, independent and unofficial.
- Passive inheritance, mutation odds and save-file import are outside the current MVP.
