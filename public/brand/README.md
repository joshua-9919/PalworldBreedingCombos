# Brand assets

The brand uses an original node-and-egg lineage system. It does not use official game artwork, character images, logos or copied trade dress.

## Files

- `logo-mark.png`: transparent master raster mark, 1254 x 1254.
- `logo-mark-512.png`: web-app icon derivative, 512 x 512.
- `apple-touch-icon.png`: Apple touch icon derivative, 180 x 180.
- `og-default.png`: default Open Graph image, 1200 x 630.
- `/favicon.svg`: compact code-native favicon optimized for very small sizes.

## Palette

- Ink: `#07110f`
- Egg gold: `#f3b849`
- Parchment: `#e7dcc2`
- Moss: `#b7c9a4`
- Coral accent: `#de765c`
- Sky accent: `#65aeca`

## Usage

Use the transparent mark on ink or other dark, quiet backgrounds. Keep standard typography for the product name; do not imitate the official Palworld wordmark. The OG image intentionally contains no generated text so page metadata remains accurate and accessible.
