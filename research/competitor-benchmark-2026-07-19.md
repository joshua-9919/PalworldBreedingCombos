# Competitor Benchmark — 2026-07-19

## Selected closest competitors

### 1. PalBreeder.com

Why it is close: Palworld 1.0 positioning, target→parents and parents→child lookup, 299-Pal/44,850-combination coverage, version/date trust signals and target-specific discovery pages.

What it does well:

- Leads with the high-intent target-Pal workflow instead of making users understand the data model first.
- Places popular breeding targets directly beside the calculator.
- Converts technical coverage into understandable proof: Pals covered, combinations, game version and update date.
- Uses target pages and related entry points to create an internal-link path beyond the calculator.

Do not copy: game artwork, wording, mutation claims, unverified ranking logic or its dataset.

### 2. Palworld.tools/breeding

Why it is close: dual-direction lookup plus Path finder and My box, which overlap with this site's owned-Pals shortest-chain differentiator.

What it does well:

- Groups distinct user jobs into clear task tabs.
- Keeps path planning and saved/owned Pals adjacent to the direct calculator.
- Explains advanced mechanics after the tool instead of blocking the primary action.
- Provides deeper follow-on tools for users who complete a direct lookup.

Do not copy: Pal artwork, database navigation, explanatory wording, inheritance calculations or extracted data.

## Applied improvements

- Replaced the prominent internal dataset ID in the global strip with user-readable coverage and freshness signals.
- Increased desktop brand/navigation type and mobile introductory type.
- Added eight verified popular-target shortcuts that open the existing reverse lookup with shareable URL state.
- Added a direct handoff from popular targets to the owned-Pals chain planner.
- Minified the production dataset payload instead of copying pretty-printed JSON.

## Preserved differentiation

The primary differentiator remains a privacy-safe, browser-local chain planner that starts from Pals the user already owns. No save-file upload, ads, login, payment, game artwork or competitor content was added.
