## Description

Palworld Breeding Combos is a free, ad-free browser tool for Palworld 1.0 players. Choose two parent Pals to see the expected child, work backward from a target to compare validated parent combinations, or plan a short breeding chain using Pals already in your Palbox. No account or save-file upload is required. Data version and verification status are shown with results. Independent, unofficial fan-made tool; not affiliated with or endorsed by Pocketpair.

## First comment

Hi Product Hunt 👋

I built Palworld Breeding Combos because the Palworld 1.0 update changed breeding data, while many players still run into old recipes, large spreadsheets, or tools that do not explain which dataset they use.

The site gives players three practical starting points:

- Choose two parent Pals and see the expected child.
- Start from a target Pal and compare direct parent combinations.
- Add Pals already in your Palbox and find a short validated breeding chain.

It is free, ad-free, requires no account, and does not ask players to upload a save file. Each result includes the game version, dataset version, generated date, and verification status.

This is an independent, unofficial fan-made tool and is not affiliated with or endorsed by Pocketpair.

I would especially value feedback on the workflow: do you usually start with two parents, a target Pal, or the Pals already in your Palbox?
